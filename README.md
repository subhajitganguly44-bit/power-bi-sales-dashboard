# 📱 Mobile Sales Dashboard

## 📊 Project Overview

An interactive **Power BI dashboard** designed to analyze mobile sales performance and provide actionable business insights.

The dashboard helps analyze sales trends, product performance, customer behavior, regional performance, and payment methods.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Excel
- CSV

## 📈 Dashboard Features

- Total sales analysis
- Sales by mobile model
- Brand-wise performance
- Regional and city-wise analysis
- Payment method analysis
- Quantity and transaction analysis
- Customer rating analysis
- Time-based sales trends

## 📂 Project Files

| File | Description |
|---|---|
| `Mobile Sales Dashboard.pbix` | Power BI dashboard |
| `Mobile Sales Data.csv` | Underlying dataset |

## 🎯 Key Objectives

- Identify top-performing mobile brands and models
- Analyze sales trends over time
- Compare regional sales performance
- Understand customer payment preferences
- Track important sales KPIs

This project was created as a **Power BI data analytics portfolio project**.
